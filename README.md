# RO 選牌助手

RO Survivors 的 Chrome Manifest V3 插件。依自訂清單，自動選擇升級技能與寶箱道具，並操作專注、放逐與全部重抽；可設定單人關卡，結算後回城找遠征隊長反覆出發。版本：`0.8.1`。

## 安裝與試用

1. 在 Chrome 網址列輸入 `chrome://extensions`。
2. 開啟右上角「開發人員模式」。
3. 點選「載入未封裝項目」，選擇本專案的 **`dist` 資料夾**。
4. 開啟或重新整理 <https://ro-survivors.com/>。
5. 點右上角「選牌助手」，在「升級技能」或「寶箱道具」分別設定順位。輸入遊戲顯示的完整名稱，或等選牌出現後按「＋清單」。
6. 拖曳清單，或使用 ↑ ↓ 排序。確認綠框推薦符合預期後，在面板頂端勾選「自動選牌」。

面板頂端可直接勾選「自動選牌」、「循環刷關」與「小範圍走動」。下方的勾選框用來設定自動選牌時要執行的動作，包括取得掉落物、組隊擲骰及技能與寶箱的選牌規則。這些規則會儲存，重新整理後只需重新勾選要啟動的功能。

「全部暫停」可一次停止這個分頁正在執行的自動功能。面板的「−」可收合，收合後仍會繼續執行。點插件工具列圖示也能重新開啟面板或暫停。

若使用 ZIP，先完整解壓縮，再載入含 `manifest.json` 的資料夾。更新版本後，回擴充功能頁按插件的重新載入，再重新整理遊戲。

### 從舊版更新

使用原本的 `dist` 路徑重新載入，既有技能與寶箱清單會保留；從 0.1.0 更新則會新增獨立的寶箱清單。不要移除插件重裝，因為移除會清除 Chrome 儲存的設定。

在「升級技能」與「寶箱道具」清單裡，每項都有「專注」、「取得後放逐」和「高品質優先」按鈕。點一下啟用，再點一下取消。「專注」與「取得後放逐」擇一，「高品質優先」可搭配其中任一項。標記依清單儲存，調整順位後仍會保留。從舊版升級時，既有項目的「高品質優先」預設關閉。

標記「高品質優先」的項目出現紫色（史詩）、傳說或神話品質時，會優先於其他候選牌。若同時出現多張符合條件的牌，先選品質較高者，同品質依清單順位，再由左至右。沒有符合條件的牌時，照原本的選牌規則處理。「取得後放逐」仍會排除已取得的升級牌。

要開始自動選寶箱，先在「寶箱道具」加入順位。沒有目標牌時會使用遊戲的「重抽全部」，次數用完後預設交由你手動選擇；也可設定選最高稀有度。空白清單不會消耗重抽次數。

「寶箱自動確認替換」預設開啟：選中的道具若需替換現有道具，插件會在翻牌確認出現後按確認。候選牌先篩選清單內道具，再比較品質，同品質才依順位；不會額外比較現有道具的價值。可取消勾選，讓所有需替換的候選牌保留手動操作。

## 小範圍走動

在城鎮就可以勾選面板頂端的「小範圍走動」。助手會在城鎮待命，進入戰鬥並讀到小地圖座標後，才以角色所在位置為中心短走、折返。勝利或死亡結算後會保留勾選，回城重開或循環刷關都會在下一場重新建立起點。走動也可以在戰鬥中單獨開啟。

展開「小範圍走動」可直接輸入活動半徑（至少 1 格的整數）與步伐間隔（至少 0.1 秒，可輸入小數）。預設為 3 格、每 2 秒一步。每步最多按鍵 0.1 秒，距離依小地圖整數座標判定。

手動按方向鍵、WASD，或用滑鼠、觸控操作場地時，助手會讓你接手移動，並保留走動勾選。放開最後一個操作後開始倒數 10 秒，期間再次操作會重新計時。倒數結束後以角色當下的位置為新中心。取消勾選或按「全部暫停」會取消待恢復的走動。

選牌、領取掉落物、切到背景或小地圖座標暫時消失時，助手會等待戰鬥畫面就緒。遇到障礙會停一下再試走。若角色被推到活動範圍外，會等回到範圍內再繼續。重新整理或重開遊戲分頁後需再次勾選，半徑與間隔會保留。

## 組隊分寶

展開遊戲內「選牌助手」的「組隊分寶」，為武器、盾牌、鎧甲、披肩、鞋子、各部位頭飾、飾品、卡片和寵物蛋分別選擇 Need（需求）或 Greed（貪婪）。武器預設 Need，其餘預設 Greed。無法辨識的種類會套用「其他」的設定。

在面板頂端勾選「自動選牌」和「組隊自動擲骰」後，助手會在分寶視窗依設定投票，每件一次。預覽模式會先顯示預定選擇。可單獨取消自動擲骰，繼續使用自動選牌。

## 目前行為

- 0.4.0 加入「循環刷關 · 遠征隊長」：**結算 → 回城 → 與遠征隊長交談 → 選擇設定關卡 → 沿用難度出發 → 戰鬥 → 再次結算**。詳見下方操作方式。
- 0.4.0 技能新增預設開啟的「先拿齊清單技能（橘色優先）」：在清單內依序選擇 **橘色（傳說）牌 → 尚未取得的新技能 → 原順位升級**。橘色或新技能同時有多張時仍照清單順位；只有清單外的新技能或橘色牌時，不會為了補齊技能而選入，仍按原本重抽／備案規則。專注、取得後放逐照常執行，標記「取得後放逐」的已取得技能即使是橘色也仍排除。可關閉此設定，恢復單純技能順位優先。
- 在面板頂端勾選「自動選牌」和「自動取得掉落物」後，掉落視窗出現「取得」時，助手會等動畫結束再點擊。這個規則適用於所有掉落物，包括組隊分寶贏得的物品。
- 0.3.2 寶箱清單內的道具同時出現時，**品質優先 → 清單順位 → 由左至右**。例如第一順位是普通 A、第二順位是傳說 B，會選 B；清單外道具不會因品質更高而取代已命中的道具。品質依稀有度標籤判斷，不是名稱結尾的強化數字。
- 標記「取得後放逐」的技能或寶箱道具首次出現時，仍依選牌設定選取。再次出現已持有的升級牌時才放逐。若已用完放逐次數，助手仍會略過該升級牌。
- 同時遇到多個標記時，先依清單從上往下專注，再從下往上放逐已取得的項目。專注及放逐需遊戲提供可用按鈕且尚有次數，之後再依各清單規則選牌或重抽。
- 取得狀態依當前牌面辨識：新技能標記代表尚未取得；無新技能標記且有已知稀有度的技能牌代表已取得的升級牌。未知狀態不放逐。這個判斷也適用於手動取得、開啟插件前已取得的技能，不會把前一局紀錄套到新一局。寶箱道具的「全新」標記代表首次取得，名稱尾端的 +1、+2 等級代表已持有。面板會顯示取得狀態。
- 技能與寶箱皆支援「沒有目標牌就全部重抽」。技能與寶箱各自使用所屬清單的標記。重抽後重新判斷，即使抽到相同牌也能依剩餘次數繼續；重抽用完、不可用或關閉後，才套用各自的未命中規則。
- 0.2.2 將選牌延遲改為每輪隨機抽取，預設 **500～1500 毫秒**，技能和寶箱共用此設定。升級前的清單、未命中規則等設定保留；舊版固定延遲會改用此預設範圍。可分別調整最短／最長時間，兩端相同即為固定延遲。
- 0.2.1 修正較矮／窄視窗中，遊戲用 CSS 隱藏輔助技能欄或升級提示後，選牌誤判而使「＋清單」停用及自動選牌失效的問題。已收錄的卡牌顯示「已加入」；未支援的畫面顯示「未支援」並提供原因。

- 拖曳優先排序、多組清單、從當前畫面加入、推薦框線、最近 30 筆操作紀錄。
- 技能與寶箱各有獨立清單和未命中規則。技能預設依橘色／尚未取得／原順位選擇；關閉「先拿齊」後先比清單順位，再比稀有度。寶箱清單內道具先比品質，再比清單順位。兩者皆相同時由左至右。寶箱命中清單但品質未知的牌，排序低於已辨識的牌；皆未知時依順位選擇。
- 名稱以完整字串比對，忽略大小寫與多餘空白。寶箱道具額外忽略名稱結尾的 ` +1`、` +2` 等強化等級；從畫面加入時也會存成基礎名稱。清單不會自動翻譯；切換遊戲語言後請重新確認名稱。
- 支援目前遊戲的繁中、英文、西班牙文、葡萄牙文升級／寶箱標題及稀有度文字。寶箱的「全新」標籤不影響稀有度比較。
- 技能與寶箱沒有命中各自目標清單，且無法再重抽時，預設等待手動操作。兩者可分別改為「最高稀有度」，但所有可選項目的稀有度都必須能辨識；未知標籤不猜測。
- 每次新牌面只抽取一次延遲，倒數／畫面更新不會反覆抽取或延後。專注、放逐與重抽造成新牌面時也會重新等待。實際等待為隨機值與遊戲動畫保護時間 `380 + 卡牌數 × 120 + 220` 毫秒之中的較大者；例如 3 張卡牌最早約 960 毫秒才點選。修改延遲範圍會重新抽取；暫停後重新啟用會用本輪原來的隨機值重新等待。
- 手動點牌、按選牌數字鍵或重抽時，取消舊操作。新的卡牌畫面會重新計算。
- 寶箱替換僅確認插件本輪選中的道具；等待翻牌就緒後才操作。暫停、手動接管、修改規則、切換到背景或卡牌改變，都會取消待執行的確認。已送出的確認無法撤回。
- 劇情物品、技能替換與未知畫面保留手動操作；不自動開啟尚未出現選牌介面的寶箱。僅辨識遊戲的整副「重抽全部」，不操作單張重抽。
- 背景分頁暫停點擊，回到分頁後繼續。合作模式的遊戲倒數仍照常進行，逾時遊戲可能自行選牌。
- 設定使用 `chrome.storage.local`；自動開關僅屬於目前分頁，重新整理後回到預覽模式。紀錄也僅保留至重新整理。
- 點牌後必須觀察到遊戲的已選狀態；專注／放逐／重抽後必須觀察到剩餘次數下降或放逐對象消失。若遊戲未確認，就停止並顯示原因，避免反覆點擊。

## 循環刷關

1. 展開「循環刷關 · 遠征隊長」。輸入遊戲顯示的完整關卡名稱，或在戰鬥／隊長關卡選單中按「使用目前關卡」。打開隊長選單後，輸入框也會列出當前已解鎖的關卡名稱。
2. 確認技能與寶箱選牌設定後，勾選面板頂端的「循環刷關」，「自動選牌」也會一併勾選。可在戰鬥、結算、城鎮或關卡選單時啟用。戰鬥中啟用會先等待本場結束。
3. 勝利或死亡結算後等 2.5 秒，點返回角色。若出現「選擇大廳」，助手會按「離線遊玩」。回到城鎮後，助手會點「與隊長交談」，選擇設定的關卡並沿用目前難度再次出發。
4. 循環期間，取消勾選「循環刷關」或「自動選牌」會一起停止這兩項功能。要連同走動一起停止，按「全部暫停」。面板顯示本分頁已結算場數（包含勝利／死亡，回城成功才計數）及最近 12 筆循環紀錄。

使用範圍與停止條件：

- 支援**單人一般關卡**。不操作劇情、跳過劇情、組隊提議或未完成遊戲的繼續／捨棄對話；遇到這些情況停下，處理完再啟用。
- 自動找隊長依回城出生點的交談提示，**不含任意城鎮位置的自動尋路**。若角色已離開交談範圍，請先靠近遠征隊長；不會與其他 NPC 交談，找不到提示 15 秒後會暫停。
- 戰鬥中沿用現有選牌功能；不代替角色移動、打開場上的寶箱或改變戰鬥設定。未命中卡牌清單又無法重抽時，仍依你的選牌設定等待手動操作或使用稀有度備案。
- 每個按鈕只送出一次，必須觀察到下一個畫面才繼續；一般按鈕等待 8 秒、回城與進場等待最多 90 秒。未確認就暫停，不重複送出。同一難度視窗必須由本次循環選定關卡後開啟，才會自動確認。
- 鎖定／不存在的關卡、無法出發、其他遊戲視窗、手動操作關卡／難度／回城按鈕或調整難度滑桿，都會停止循環與自動選牌；關卡、對話或結算時按 Escape、Enter、空白鍵也會交回手動。變更目標關卡會停止待執行操作，需要重新啟用。既有選牌確認失敗時，循環一併暫停。
- 分頁在背景時停止點擊，返回後重新等待；一般選牌和循環共用此限制。重新整理只保留關卡名稱與選牌設定，不自動恢復開關或場數。

## 開發

需要 Node.js 22 或以上。`dist` 已編譯完成，單純安裝不需要 Node.js。

```powershell
npm ci
npm run build
npm run check
```

瀏覽器測試需要 Chromium。如果未安裝 Playwright 的 Chromium，執行 `npx playwright install chromium`。Windows 也會偵測現有的 Playwright Chromium；可使用環境變數 `RO_CHROMIUM_PATH` 指定測試瀏覽器。

修改後執行 `npm run build`，再重新載入 Chrome 插件與遊戲頁面。

| 位置 | 用途 |
| --- | --- |
| `src/core.ts` | 名稱、稀有度、順位規則、設定驗證 |
| `src/adapter.ts` | 遊戲 DOM 辨識，遊戲改版時優先檢查 |
| `src/engine.ts` | 等待動畫、取消操作、每輪只選一次、確認結果 |
| `src/run-adapter.ts` / `src/run-loop.ts` | 城鎮、隊長、關卡、難度與結算的辨識及循環控制 |
| `src/loot.ts` | 掉落物的取得提示、動畫等待與防止重複點擊 |
| `src/panel.ts` / `src/panel.css` | 遊戲內的 Shadow DOM 控制面板 |
| `src/content.ts` / `src/storage.ts` | 插件啟動、設定保存、訊息處理 |
| `src/popup.ts` | Chrome 工具列彈出視窗 |
| `extension/` | Manifest 與靜態資源 |
| `dist/` | 可直接載入 Chrome 的成品 |
| `tests/` | 規則測試及實際載入插件的瀏覽器測試 |

## 驗證範圍

以 2026-11-13 的公開前端結構為依據，核心選擇器為 `#picker`、`#pk-title`、`#pk-gain`、`#lu-sockets`、`#pk-cards .pk-card`、`.pk-name`、`.pk-badge`。技能取得狀態另使用 `.pk-ribbon` 新技能標記；不因矮視窗用 CSS 隱藏標記而改變判斷。操作按鈕以 `.pk-acts .pk-act`、`#pk-bar .pk-act` 的文字與 `small` 剩餘次數辨識。`data-i` 僅為本輪索引，不作為技能永久 ID。

循環使用 `body.in-lobby`、`#lobby-ui`、`#lobby-prompt`、`#stages`、`#stg-list .stg-card`、`#stg-detail .stg-banner-text b`、`#stg-go`、`#npc-dialog`、`#npc-text .diff input[data-key]`、`#npc-options button.primary`、`#gameover`、`#btn-restart` 與 `#hud`。隊長交談與難度確認支援繁中、英文、西班牙文、葡萄牙文標籤；關卡名稱依當前語言完整比對。

瀏覽器測試將編譯後的真實 MV3 插件載入獨立 Chromium，再使用自行製作的選牌 HTML 測試。測試場景未包含遊戲程式或美術資源。模擬測試不等同於登入遊戲後的實戰驗證；實戰的職業、特殊卡牌及新版 UI 可在試用過程中調整。

擴充功能只宣告 `storage` 權限，content script 僅匹配 `https://ro-survivors.com/*`。無後端服務或遠端執行程式。

參考：<https://ro-survivors.com/>、[Chrome content scripts](https://developer.chrome.com/docs/extensions/develop/concepts/content-scripts)、[Chrome storage](https://developer.chrome.com/docs/extensions/reference/api/storage)。
