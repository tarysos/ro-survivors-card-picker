# RO 選牌助手

RO Survivors 的 Chrome Manifest V3 插件。依自訂優先清單，自動選擇升級技能與寶箱道具，並操作專注、放逐與全部重抽。版本：`0.3.0`。

## 安裝與試用

1. 在 Chrome 網址列輸入 `chrome://extensions`。
2. 開啟右上角「開發人員模式」。
3. 點選「載入未封裝項目」，選擇本專案的 **`dist` 資料夾**。目前位置：`C:\Users\tarys\repos\ro\dist`。
4. 開啟或重新整理 <https://ro-survivors.com/>。
5. 點右上角「選牌助手」，在「升級技能」或「寶箱道具」分別設定順位。輸入遊戲顯示的完整名稱，或等選牌出現後按「＋清單」。
6. 拖曳清單，或使用 ↑ ↓ 排序。先查看綠色框線推薦是否正確，再按「啟用自動選牌」。

面板的「−」可收合；收合後仍會繼續監看。插件工具列圖示可重新開啟面板，或暫停目前遊戲分頁。

若使用 ZIP，先完整解壓縮，再載入含 `manifest.json` 的資料夾。更新版本後，回擴充功能頁按插件的重新載入，再重新整理遊戲。

### 從舊版更新

使用原本的 `dist` 路徑重新載入，既有技能與寶箱清單會保留；從 0.1.0 更新則會新增獨立的寶箱清單。不要移除插件重裝，因為移除會清除 Chrome 儲存的設定。

0.3.0 預設開啟專注、放逐，以及技能／寶箱的全部重抽，可在「選牌設定」分別關閉。升級技能第一順位標示「專注」，最後兩順位標示「放逐」；清單至少 3 項才啟用放逐，避免與第一順位重疊。

要開始自動選寶箱，先在「寶箱道具」加入順位。沒有目標牌時會使用遊戲的「重抽全部」，次數用完後預設交由你手動選擇；也可設定選最高稀有度。空白清單不會消耗重抽次數。

「寶箱自動確認替換」預設開啟：選中的道具若需替換現有道具，插件會在翻牌確認出現後按確認。此規則比較目前候選牌的順位，不會額外比較現有道具的價值。可取消勾選，讓所有需替換的候選牌保留手動操作。

## 目前行為

- 0.3.0 技能操作順序為：專注第一順位 → 放逐最後一順位 → 放逐倒數第二順位 → 選擇最高順位的目標牌。各動作只在對應牌出現、按鈕可用且有剩餘次數時執行；已專注的牌不再消耗次數。放逐名單即使次數用完，也不會被自動選取。
- 技能與寶箱皆支援「沒有目標牌就全部重抽」。技能目標不包含放逐名單；寶箱使用獨立清單，且不套用專注／放逐。重抽後重新判斷，即使抽到相同牌也能依剩餘次數繼續；重抽用完、不可用或關閉後，才套用各自的未命中規則。
- 0.2.2 將選牌延遲改為每輪隨機抽取，預設 **500～1500 毫秒**，技能和寶箱共用此設定。升級前的清單、未命中規則等設定保留；舊版固定延遲會改用此預設範圍。可分別調整最短／最長時間，兩端相同即為固定延遲。
- 0.2.1 修正較矮／窄視窗中，遊戲用 CSS 隱藏輔助技能欄或升級提示後，選牌誤判而使「＋清單」停用及自動選牌失效的問題。已收錄的卡牌顯示「已加入」；未支援的畫面顯示「未支援」並提供原因。

- 拖曳優先排序、多組清單、從當前畫面加入、推薦框線、最近 30 筆操作紀錄。
- 技能與寶箱各有獨立清單和未命中規則。清單順位優先於稀有度。同一技能／道具的多個選項以稀有度決定，再由左至右。
- 名稱以完整字串比對，忽略大小寫與多餘空白。寶箱道具額外忽略名稱結尾的 ` +1`、` +2` 等強化等級；從畫面加入時也會存成基礎名稱。清單不會自動翻譯；切換遊戲語言後請重新確認名稱。
- 支援目前遊戲的繁中、英文、西班牙文、葡萄牙文升級／寶箱標題及稀有度文字。寶箱的「全新」標籤不影響稀有度比較。
- 技能與寶箱沒有命中各自目標清單，且無法再重抽時，預設等待手動操作。兩者可分別改為「最高稀有度」，但所有可選項目的稀有度都必須能辨識；未知標籤不猜測。
- 每次新牌面只抽取一次延遲，倒數／畫面更新不會反覆抽取或延後。專注、放逐與重抽造成新牌面時也會重新等待。實際等待為隨機值與遊戲動畫保護時間 `380 + 卡牌數 × 120 + 220` 毫秒之中的較大者；例如 3 張卡牌最早約 960 毫秒才點選。修改延遲範圍會重新抽取；暫停後重新啟用會用本輪原來的隨機值重新等待。
- 手動點牌、按選牌數字鍵或重抽時，取消舊操作。新的卡牌畫面會重新計算。
- 寶箱替換僅確認插件本輪選中的道具；等待翻牌就緒後才操作。暫停、手動接管、修改規則、切換到背景或卡牌改變，都會取消待執行的確認。已送出的確認無法撤回。
- 劇情物品、技能替換與未知畫面保留手動操作；不自動開啟尚未出現選牌介面的寶箱。僅辨識遊戲的整副「重抽全部」，不操作單張重抽。
- 背景分頁暫停點擊，回到分頁後繼續。合作模式的遊戲倒數仍照常進行，逾時遊戲可能自行選牌。
- 設定使用 `chrome.storage.local`；自動開關僅屬於目前分頁，重新整理後回到預覽模式。紀錄也僅保留至重新整理。
- 點牌後必須觀察到遊戲的已選狀態；專注／放逐／重抽後必須觀察到剩餘次數下降或放逐對象消失。若遊戲未確認，就停止並顯示原因，避免反覆點擊。

## 開發

需要 Node.js 22 或以上。`dist` 已編譯完成，單純安裝不需要 Node.js。

```powershell
npm ci
npm run build
npm run check
```

瀏覽器測試需要 Chromium。如果未安裝 Playwright 的 Chromium，執行 `npx playwright install chromium`。Windows 也會偵測現有的 Playwright Chromium；可使用環境變數 `RO_CHROMIUM_PATH` 指定測試瀏覽器。

修改後執行 `npm run build`，再重新載入 Chrome 插件與遊戲頁面。

| 位置 | 用途 |
| --- | --- |
| `src/core.ts` | 名稱、稀有度、順位規則、設定驗證 |
| `src/adapter.ts` | 遊戲 DOM 辨識，遊戲改版時優先檢查 |
| `src/engine.ts` | 等待動畫、取消操作、每輪只選一次、確認結果 |
| `src/panel.ts` / `src/panel.css` | 遊戲內的 Shadow DOM 控制面板 |
| `src/content.ts` / `src/storage.ts` | 插件啟動、設定保存、訊息處理 |
| `src/popup.ts` | Chrome 工具列彈出視窗 |
| `extension/` | Manifest 與靜態資源 |
| `dist/` | 可直接載入 Chrome 的成品 |
| `tests/` | 規則測試及實際載入插件的瀏覽器測試 |

## 驗證範圍

以 2026-11-13 的公開前端結構為依據，核心選擇器為 `#picker`、`#pk-title`、`#pk-gain`、`#lu-sockets`、`#pk-cards .pk-card`、`.pk-name`、`.pk-badge`。操作按鈕以 `.pk-acts .pk-act`、`#pk-bar .pk-act` 的文字與 `small` 剩餘次數辨識。`data-i` 僅為本輪索引，不作為技能永久 ID。

瀏覽器測試將編譯後的真實 MV3 插件載入獨立 Chromium，再使用自行製作的選牌 HTML 測試。測試場景未包含遊戲程式或美術資源。模擬測試不等同於登入遊戲後的實戰驗證；實戰的職業、特殊卡牌及新版 UI 可在試用過程中調整。

擴充功能只宣告 `storage` 權限，content script 僅匹配 `https://ro-survivors.com/*`。無後端服務或遠端執行程式。

參考：<https://ro-survivors.com/>、[Chrome content scripts](https://developer.chrome.com/docs/extensions/develop/concepts/content-scripts)、[Chrome storage](https://developer.chrome.com/docs/extensions/reference/api/storage)。
